========================================
  长沙理工 · 校园网一键连接
  使用说明
========================================

【这是什么】
一个双击就能连校园网的小工具。自动检测网络、必要时切换到校园网 WiFi、
用你的学号密码完成认证。不用装 Python，不用每次开网页手动登录。

【怎么用】
1. 把「校园网一键连接.exe」解压到一个固定的文件夹
   （建议 D:\校园网 或桌面，不要放在压缩包里直接双击运行）
2. 双击它
3. 第一次运行会让你输入三样东西：
      学号（工号）
      密码（输入时屏幕上不显示，这是正常的，打完直接回车）
      服务序号：直接回车就行（默认 0 = 校园网）
4. 以后每次双击即可，不用再输

连上后会显示「[OK] 校园网登录成功」，窗口可以直接关掉。

【想让电脑开机自动连？】
1. 在放 exe 的文件夹空白处，按住 Shift + 鼠标右键
2. 选「在此处打开 PowerShell 窗口」（或「打开终端」）
3. 输入下面这一行，回车：

   .\校园网一键连接.exe --enable-autostart

以后开机会自动连接。想取消，把 --enable-autostart 换成：

   .\校园网一键连接.exe --disable-autostart

（开机时会闪一个黑色小窗口，连上后几秒自动关闭，属于正常现象）

【换账号 / 改了密码】
删掉 exe 旁边那个 config.json，重新双击，按提示重填一遍。

【连不上怎么排查】
1. 先看电脑有没有连上 csust 开头的 WiFi，连手机热点是没用的
2. 如果是宽带账号（电信/联通/移动），服务序号不能填 0：
      0 = 校园网   1 = 电信   2 = 联通   3 = 移动
   填错会提示「运营商标记错误」之类的话，删掉 config.json 重填
3. 开着 Clash 之类代理软件的，脚本会提示检测到虚拟网卡。
   一般不影响；如果反复连不上，先退出代理再试
4. 还是不行，把 exe 旁边的 login.log 发给懂电脑的同学看

【安全说明】
· 账号密码只保存在你自己电脑的 config.json 里，不会上传到任何服务器
· 密码做了 base64 编码（只是防止一眼被看到，不是加密）。
  所以别把 config.json 发给别人，也别截图
· 这是同学自己写的辅助工具，不是学校官方出品，
  用的是学校正常的校园网认证接口，只是帮你省掉手动点网页那一步

【杀毒软件报毒？】
这类小工具经常被 Windows Defender 误报（打包方式本身容易被判可疑）。
如果是班级群里拿到的，可以放心加白名单：
Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项 → 添加排除项 → 选这个文件夹

【已知限制】
· 只在本校校园网环境有效（csust-* 的 WiFi），在家或热点用不上，会直接提示后退出
· 一个账号同时只能在线一台设备，在宿舍电脑登录会把手机顶下线
· 认证依赖学校网关，若学校升级了认证系统，这个小工具可能失配，需要重新适配
